# Java Projects – Collections

This repo contains many small-to-medium Java projects, such as:

- ATM interface  
- Library Management  
- Billing System  
- Chat Application  
- Snake Game  
- Encryption / Decryption  
- Student Management System  
- …and more!

- Lists, Maps, Sets, Queues from Java Collections Framework  
- Object oriented design  
- File I/O, Exception Handling  
- Algorithms & logic  
- Modular project structure
